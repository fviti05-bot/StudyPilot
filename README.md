# 🎓 StudyPilot

StudyPilot is an AI-powered study planner built for university students.

## Features

- 📅 Exam management
- 🤖 AI-generated study plans
- 📊 Study readiness score
- 🧠 Smart flashcards
- ❓ AI quizzes
- 📈 Progress tracking
- 🎯 Daily study missions

## Mission

Help students study smarter, reduce stress and improve exam performance using artificial intelligence.
